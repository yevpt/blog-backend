# 功能地图

本文从业务模块角度描述当前后端能力，方便接手时定位代码入口。

## 内容与互动

- **文章管理**：草稿/发布、分类、标签、推荐排序、移动端封面、音乐关联、PV/UV 统计。
- **碎语**：类 X 短贴，支持图片、置顶、Feed、详情、点赞、浏览统计。
- **评论系统**：文章、碎语、留言板共用树形回复与点赞能力，支持编辑、删除和管理端查询。
- **留言板**：公开留言列表、登录后发布/编辑/删除、回复与点赞。
- **友链管理**：公开列表与后台维护，支持站点头像/截图类资源。

## 用户与身份

- **用户管理**：用户名、邮箱、手机、头像、资料、社交链接、在线状态、最近活跃与账号禁用。
- **角色权限**：`ROLE_ADMIN`、`ROLE_VIP`、`ROLE_NORMAL` 三档角色。
- **认证链路**：JWT access/refresh token、bcrypt 密码、邮箱验证码、注册图形验证码。
- **第三方登录**：GitHub、Gitee、QQ、微博、百度，通过 Provider Adapter 接入；OAuth state 存 Redis，支持平台启用 PKCE。

OAuth 认证身份只使用 `user`、`social_user`、`social_user_auth` 三张表；`user_social_link` 仅用于用户资料里的社交链接展示，不参与登录或绑定判断。

## 媒体与存储

- **对象存储**：Garage S3 兼容接口，统一由 `pkg/storage` 封装。
- **CDN 私有访问**：支持 CDN 签名 URL 与 Redis URL 缓存。
- **图片处理**：临时图片、头像、分类图标/封面、碎语图片、审核预览图。
- **音乐资源**：艺术家、专辑、歌曲管理，上传音频后解析元数据。
- **图片 CDN 代理**：`internal/router/cdn_image.go` 注册图片回源与处理路由，使用 `X-Origin-Auth` 做回源保护。

对象存储细节见 [pkg/storage](../pkg/storage/README.md)。

## 通知与后台

- **站内信**：业务事件写入通知事件，由 Dispatcher 异步解析收件人与偏好，写入用户收件箱。
- **邮件通知**：按全站、用途、角色、接收人四层配额规划邮件批次，再由 sender 发送。
- **后台仪表盘**：内容总量、近期互动、用户统计概览。
- **操作日志**：管理端用户操作与审核治理相关动作会落库记录。

运行链路见 [运行时与安全](runtime-operations.md)。

## 访问统计

自建埋点系统覆盖：

- 前端 `/collect` 上报。
- UA、referer、设备、GeoIP 富化。
- Redis 实时层维护今日数据与在线状态。
- 异步落库与每日 Rollup。
- 后台查询概览、趋势、页面、维度、友链、路径、漏斗、实时在线。
- 前台公开统计接口：`/analytics/public/summary`、`/analytics/public/popular`。

完整配置见 [站点分析配置](analytics-configuration.md)。

## 内容审核

审核覆盖评论、留言、回复、碎语与相关图片：

- 文本规则、关键词/正则规则索引、规则导入与发布。
- 新用户、普通用户、可信用户、受限用户分层策略。
- 先发后审、先审后发、阻断、人工通过/修正/驳回。
- 禁言、封禁、全站注册/发布控制、隐藏/恢复内容。
- 审核邮件摘要、清理 worker、历史 UGC 迁移工具。

上线与回滚见 [内容审核上线与回滚](moderation-rollout.md)，规则索引性能见 [审核规则索引基准](moderation-rule-index-benchmark.md)。
